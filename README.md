# StatBot: position sizing

A small Python position-size calculator for trading risk.

```sh
python position_sizing.py
```

The calculator was created by [Ihsan Ali](https://github.com/IhsanAliOfficial/position-sizing-calculator_bot) and is redistributed here under the MIT license. See [LICENSE](LICENSE) for the original copyright and license terms.

It is a simple example and does not execute trades or connect to exchanges.
